# Операции ГИИС ДМДК

Список методов ГИИС, которые используются в нашем приложении.

## Реализованные операции

### 1. Создание квитанции (SendBuyingup)
- **Что делает:** Создаёт черновик квитанции в ГИИС
- **Типы квитанций:**
  - DT_RECEIPT_FOR_MANUFACTURING — изготовление
  - DT_RECEIPT_FOR_REPAIR — ремонт
  - DT_RECEIPT_FOR_BUYINGUP — скупка
- **Статус после создания:** DS_DRAFT (черновик)
- **Возвращает:** Номер квитанции (P-02-XXXXXXX-26)
- **Пример:** P-02-000005958-26 (наша тестовая)

### 2. Проверка статуса (CheckBuyingup)
- **Что делает:** Проверяет текущий статус квитанции
- **Статусы:**
  - DS_DRAFT — черновик
  - DS_ACCEPTED — принята
  - DS_REJECTED — отклонена
- **Используется:** После отправки, чтобы дождаться готовности

## Планируемые операции

### 3. Добавление партий (SendBatchBuyingup)
- **Что делает:** Добавляет лом/металл в квитанцию
- **Данные:** Вес, проба, ХЧМ, количество
- **Источник данных:** Смарт-процесс Битрикс24

### 4. Опробование и клеймение (SendBuyingup + другой тип)
- **Что делает:** Отправляет заготовки в пробирную палату
- **Источник данных:** Смарт-процесс Битрикс24

### 5. Получение УИН (SendGetBatch)
- **Что делает:** Запрашивает идентификационный номер партии
- **Возвращает:** УИН вида 6432600000491524

## Справочные методы

### 6. Получение справочников (SendGetGlossary)
- **Что делает:** Загружает коды металлов, проб, камней
- **Используется:** Для валидации данных

### 7. Создание заготовки ювелирного изделия (SendProduct)
- **Что делает:** Создает партию типа PREPACK_PRODUCT (заготовка изделия)
- **Метод:** SendProduct
- **Ключевые поля:**
  - `type = PREPACK`
  - `subType = PREPACK_PRODUCT` (НЕ HOUSEHOLD_ITEMS_PREPACK!)
  - `category = JT_RING` (или другая категория изделия)
  - `phase = MANUFACTURING_PRODUCT`
  - `process = STORED`
- **Для ИП:** Используем `<legal><OGRN>0000000000000</OGRN></legal>` (обход XSD)
- **Обязательная опция:** `MANUFACTURING_PRODUCT_NEWFORMAT`
- **Возвращает:** УИН новой заготовки (например, 6432600000XXXXXX)
- **Пример скрипта:** `/app/my_new_app/create_prepack_final.py`
- **Успешный тест:** Рабочий контур, квитанция P-02-011643376-26
