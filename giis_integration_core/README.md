# Giis Integration Core — Ядро интеграции с ГИИС ДМДК

## 📖 Описание
Модульная система интеграции ювелирной мастерской "Златокузница" (Битрикс24) с государственной информационной системой ГИИС ДМДК.

## 🏗️ Архитектура
БИТРИКС24 → вебхук → giis_integration_core → stunnel → ГИИС ДМДК

## ✅ Реализованные модули

### 05_receipts — Квитанции
- **05_02_buyingup_repair/** — Скупка, комиссия, ремонт, изготовление
  - ✅ `create_buyingup.py` — создание квитанции на скупку (SendBuyingup)
  - ✅ `check_buyingup.py` — проверка статуса квитанции (CheckBuyingup)
  - ✅ `create_repair.py` — создание квитанции на ремонт (DT_RECEIPT_FOR_REPAIR)
  - ✅ `create_manufacturing.py` — создание квитанции на изготовление (DT_RECEIPT_FOR_MANUFACTURING)
